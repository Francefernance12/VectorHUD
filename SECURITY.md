# Security Policy

## Supported Versions
Only the latest released version of VectorHUD receives security updates.

## Reporting a Vulnerability
If you discover a security vulnerability in VectorHUD (especially relating to SQLite database security, local key encryption, or WebView process boundary escapes), please do **NOT** open a public issue.

Instead, please send a detailed report through our standard issues channel requesting a private security exchange link, or reach out to the project maintainers via the contact options listed on their GitHub profiles.

We will acknowledge receipt within 48 hours and work with you to analyze and patch the vulnerability before public disclosure.
