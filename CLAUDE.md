## Application Building Context

Read the following files in order before implementing
or making any architectural decision:

1. `context/project/project-overview.md` — product definition, goals, features, and scope
2. `context/technical/architecture.md` — system structure, boundaries, storage model, and invariants
3. `context/standards/ui-context.md` — theme, colors, typography, and component conventions
4. `context/standards/code-standards.md` — implementation rules and conventions
5. `context/standards/ai-workflow-rules.md` — development workflow, scoping rules, and delivery approach
6. `context/technical/data-flow.md` — data & event flow structure
7. `context/technical/database-schema.md` — SQLite definitions
8. `context/technical/Decisions.md` — architectural decisions log
9. `context/project/progress-tracker.md` — current phase, completed work, open questions, and next steps

Update `context/project/progress-tracker.md` after each
meaningful implementation change.

If implementation changes the architecture, scope, or
standards documented in the context files, update the
relevant file before continuing.
